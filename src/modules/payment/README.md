# PAYMENT МОДУЛЬ

## юкасса
перед создание заказа/подписки нужно в платежной системе иметь 2 хука
1) для подписок
2) для заказов
после успешной обработки запроса от хука нужно отдавать 200

по логике при создании подписки или создании заказа, подписка или заказ
создаются в статусе pending и отправляется запрос на создание платежа в юкасса
после подтверждения платежа юкасса отправляет на хук ответ со статусом,
далее статус заказа или подписки меняется на активный.
