# tiers модуль

Уровни (Initiate / Member / Core / Inner).
```
tiers (
  id          uuid pk,
  code        text unique, -- initiate / member / core / inner
  name        text,
  min_months  int,         -- требуемый стаж
  priority    int          -- для сортировки
)
```
Уровень определяет можно ли пользователю покупать тот или иной дроп
на данный момент существует несколько уровней
INITIATE - только зарегестрировался без подписки

Member - Только купил подписку, может покупать дропы минимальным тиром 2
Core - 3-5 месяцев с подпиской, может покупать дропы с минимальным тиром 3
Inner - 6+ месяцев, может покупать дропы с минимальным тиром 4
